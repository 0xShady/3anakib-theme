# Change Log

All notable changes to the "3anakib" extension are documented in this file.

## [2.0.0]

### Added

- **3anakib darker**: near-black blue backgrounds, Nord-inspired UI accents and brighter syntax colors.
- **Zen Mode** (`3anakib: Toggle Zen Mode`, `cmd+alt+z` / `ctrl+alt+z`): hides editor and title bar clutter, and restores your settings when turned off.
- **Optional CSS extras** (`3anakib: Choose CSS Extras`): Spotlight-style command palette, monospace UI, and a quieter title/status bar, applied through the Custom CSS and JS Loader extension. See the README before enabling.
- Semantic highlighting, bracket pair colors, a full terminal ANSI palette, and colors for find matches, git decorations, gutter, minimap, panels, menus, peek view, quick input and notifications.
